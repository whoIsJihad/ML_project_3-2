## Category Definitions

| Category | Description | Example |
|----------|-------------|---------|
| **Logic** | Flawed reasoning, invalid proofs, circular arguments | "Assuming conclusion in the proof" |
| **Edge Cases** | Missing boundary conditions, special cases | "Didn't consider empty input" |
| **Complexity** | Wrong big-O, missing constants, ignoring condition number | "Said O(n) but it's O(n log n)" |
| **Assumptions** | Unstated prerequisites, implicit assumptions | "Assumed independence without stating it" |
| **Trade-offs** | Failed to analyze multiple approaches, missed downsides | "Only analyzed time, ignored space" |
| **Abstraction** | Wrong level of detail, too high-level or too low-level | "Gave vague answer when math was needed" |

## How to Use This Log

1. **After each session**: Add weaknesses identified in feedback
2. **Every 5 sessions**: Look for patterns (which category appears most?)
3. **Every 7 sessions**: Use this log to prepare for oral exam
4. **Ongoing**: Revisit cross-links for weak areas

---

## Reinforcement Schedule

If a weakness appears in **3+ sessions** in the same category:
- Schedule a **deep-dive session** on that topic
- Work through advanced problems in that area
- Request additional stress questions
