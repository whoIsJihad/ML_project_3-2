## 💡 Study Tips

1. **Budget time**: Each session needs 3-5 hours total
   - Theory reading: 30-60 min
   - Conceptual questions: 60-90 min
   - Applied problem: 90-120 min
   - Feedback review: 30 min

2. **Work offline first**: Write your answers before sharing them

3. **Be precise**: Show calculations, state assumptions, consider edge cases

4. **Track patterns**: If you struggle with the same type of problem repeatedly, note it in your weakness log

5. **Use cross-links**: Each session has reinforcement links—follow them when concepts are unclear

## ❓ FAQ

**Q: Do I need to complete sessions in order?**  
A: Yes, for the first cycle (Sessions 1-7). After that, you can jump to specific domains based on your weakness log.

**Q: What if I get stuck on a question?**  
A: Attempt it fully first. If truly stuck, state what you've tried and where you're blocked. I'll provide targeted hints (not full solutions).

**Q: How long should I spend on each session?**  
A: 3-5 hours total. Don't rush. Quality > speed.

**Q: Can I skip the applied problem?**  
A: No. Phase 3 is where integration happens. It's the most valuable part.

**Q: What if I want to go deeper on a topic?**  
A: Use the cross-links at the bottom of each session. Also, request additional stress questions on specific topics.
