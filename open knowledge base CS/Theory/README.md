# Theory Knowledge Base

Comprehensive CS theory reference with university-level depth, designed for focused study (2-4 hours per course).

## Structure

```
Theory/
├── INDEX.md                            # Navigation and study paths
├── README.md                           # This file
├── 01_Digital_Logic_Design.md          # Boolean algebra, gates, circuits
├── 02_Computer_Architecture.md         # CPU design, pipelines, memory
├── 03_Microprocessors_Microcontrollers.md  # Embedded systems, assembly
├── 04_Algorithms_Data_Structures.md    # DSA fundamentals
├── 05_Database_Systems.md              # SQL, transactions, indexing
├── 06_Computer_Networks.md             # OSI, TCP/IP, protocols
├── 07_Operating_Systems.md             # Processes, memory, filesystems
├── 08_C_Programming.md                 # C language reference
├── 09_Cpp_Programming.md               # Modern C++ and STL
└── 10_Discrete_Math_Probability.md     # Logic, combinatorics, probability
```

## How to Use

1. **Quick Reference:** Use INDEX.md to find specific topics
2. **Deep Study:** Read files in order within their category
3. **Cross-Reference:** Follow WikiLinks [[like_this]] to related topics
4. **Practice:** Pair theory with problem-solving in cycle folders

## Design Principles

- **Depth:** University undergraduate level, core concepts only
- **Format:** Obsidian-compatible markdown with WikiLinks
- **Time:** Each file is completable in 2-4 hours
- **Focus:** Filtered to essential knowledge for CS success
