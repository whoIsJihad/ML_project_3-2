## 🆕 What's New in Cycle 4

### Research Frontier
- Cutting-edge papers (2023-2026)
- Unsolved problems
- Academic-level discourse
- Conference/journal depth

### Design from First Principles
- No templates or patterns given
- Derive solutions from constraints
- Justify every design decision
- Multiple competing valid approaches

### Teaching-Level Understanding
- Explain concepts to others
- Create your own examples
- Identify common misconceptions
- Build intuition from formalism

### Contribution Mindset
- Critique existing work
- Identify limitations
- Propose improvements
- Understand research methodology
