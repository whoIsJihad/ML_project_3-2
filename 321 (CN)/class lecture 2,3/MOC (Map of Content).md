# MOC - Lecture 2: The Network Layer

Welcome to the notes for lecture 2, focusing on the **Network Layer**. This is the layer where the magic of routing data across vast networks like the internet happens.

## Core Concepts

- [[🌐 The Network Layer]]: An introduction to the Network Layer's role and function in the OSI model.
- [[🚦 Packet Switching]]: Understanding the fundamental "store-and-forward" technique that governs how data travels.
- [[📬 Network Service Models]]: Exploring the two main philosophies for data delivery: Connection-Oriented (Virtual Circuits) and Connectionless (Datagrams).
- [[🗺️ Routing Algorithms]]: Diving into the brains of the network layer, exploring how path decisions are made and the trade-offs involved.
- [[⭐ Optimality Principle]]: Learning the foundational concept that underpins all efficient routing algorithms.
