## Study Guide: Subnets & IP Fundamentals

### 1. Subnet Definition

- **Subnet $\rightarrow$ Subnetwork:** In your notes, a subnet is defined as a collection or "set of routers" that form a part of a larger network.
    
- **Function:** It essentially segments a network into smaller, manageable pieces to improve performance and security.
    

### 2. IP Addressing Structures

You’ve noted the two primary versions of the Internet Protocol currently in use:

- **IPv4:** Uses **32-bit** addresses, which are typically represented in **4 octets** (e.g., 192.168.1.1).
    
- **IPv6:** Uses **128-bit** addresses to solve the address exhaustion problem of IPv4.
    

### 3. Packet Switching Logic

The notes in Bengali explain the "Why" behind packet switching:

- **Decision Making:** Packet switching is used because the system must decide **which direction** (which path) a packet should take to reach its destination.
    
- Unlike circuit switching, each packet is handled independently, allowing the network to make real-time routing decisions.
    

### 4. The "Missing" IPv5

- **Question:** "Why is there no IPv5?" (IPV-5 কেন নেই?).
    
- **Explanation:** (Since your note just asks the question): IPv5 was actually a real protocol called the **Internet Stream Protocol (ST)**. It was designed for experimental streaming of voice and video. Because it used the same header field as IPv4 but wasn't intended for general use, it was never publicly deployed, and the world skipped straight to IPv6 for the next generation of general-purpose addressing.
