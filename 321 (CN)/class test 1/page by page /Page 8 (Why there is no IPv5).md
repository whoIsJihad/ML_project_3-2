# **Why there is no IPv5** (this was 32 bit too)

- **IPv5 was never intended as a real IP version.**
    
- The number **5** was used by an experimental protocol called **Internet Stream Protocol (ST / ST-II)** in the late 1970s–80s.
    
- It was designed for **real-time data (voice, video)**, not general packet routing.
    
- The protocol **failed to gain adoption** and was abandoned.
    
- To **avoid version number conflicts** in IP headers and software, the next real upgrade after IPv4 was named **IPv6**, skipping 5.
    

**In short:**  
IPv5 existed only as an experiment, was abandoned, and the version number was skipped to prevent confusion.
