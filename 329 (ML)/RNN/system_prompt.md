

## Prompt

Write a **comprehensive, interlinked set of Markdown notes** with full support for `[[wikilinks]]` (Obsidian-style).

Use `[[placeholder]]` as the root note and infer all necessary context and prerequisite structure from it.

### Requirements

* Target audience: **absolute beginner**, but **do not simplify conceptually**
* **No childish analogies**, metaphors, or motivational talk
* Treat the notes as a **single, self-contained study reference**, not a quick guide
* **Do not include summaries, TL;DRs, or high-level overviews**
* Each concept must be developed **from first principles**, with:

  * formal definitions
  * mathematical notation where applicable
  * step-by-step derivations
  * precise terminology
  * assumptions explicitly stated
* Every major concept should be its **own note**, connected using `[[wikilinks]]`
* Introduce and link **prerequisite concepts before using them**
* Avoid “hand-wavy” explanations — be explicit and exact
* Prefer correctness and completeness over brevity
* The final output should be suitable as a **primary textbook replacement**, not supplementary notes

### Structure Guidelines

* Use clear hierarchical headings
* Create dense cross-linking between related concepts
* Maintain consistent notation across all notes
* Assume the reader is serious and willing to read long material
* Do not ask questions or leave exercises unless explicitly required

### Output Format

* Markdown only
* Use `[[wikilinks]]` instead of inline links
* No summarizing sections
