### Study Guide 1: Learning Probabilistic Models
This guide covers the core concepts of probabilistic modeling, focusing on Maximum Likelihood, Maximum a Posteriori, and Mixture Models.

#### Bayesian Learning Framework
*   **Hypothesis Prior $(P(h_i))$:** Our initial belief about the probability of a hypothesis before seeing any data.
*   **Likelihood $(P(d|h_i))$:** The probability of observing the data given a specific hypothesis.
*   **Prediction:** Combining prior beliefs and likelihood to make predictions about new data.

#### Maximum a Posteriori (MAP) Hypothesis
*   **Goal:** Find the single most probable hypothesis given the data.
*   **Formula:** $h_{MAP} = \text{argmax}_{h_i} P(h_i | d)$
*   **Advantage:** Transforms a summation problem into an optimization problem, which is often easier to solve.

#### Maximum-Likelihood (ML) Hypothesis
*   **Assumption:** Assumes a uniform prior over the hypothesis space (all hypotheses are initially equally likely).
*   **Goal:** Find the hypothesis that maximizes the likelihood of the data.
*   **Formula:** $h_{ML} = \text{argmax}_{h_i} P(d | h_i)$

#### ML Parameter Learning (Continuous Model)
*   **Example:** Learning parameters for a Gaussian distribution $N(\mu, \sigma^2)$.
*   **Log-Likelihood:** We use the log-likelihood because it turns products into sums, making differentiation easier.
*   **Maximization:** Taking partial derivatives of the log-likelihood with respect to the mean ($\mu$) and standard deviation ($\sigma$) and setting them to zero to find the optimal parameters.

#### Conditional Distribution $P(Y|X)$
*   **Assumption:** $Y$ follows a Gaussian distribution with a fixed standard deviation, where the mean is linearly dependent on $X$ ($\mu = \theta_1 x + \theta_2$).
*   **Finding Parameters:** Maximizing the log-likelihood is mathematically equivalent to minimizing the squared error: $(y - (\theta_1 x + \theta_2))^2$.

#### Mixture Distribution
*   Consists of $k$ components.
*   Each component is a probhability distribution itself.
*   $C$ is a random variable indicating the component.

#### Mixture of Gaussians (GMM)
*   **Definition:** Each component in the mixture is a multivariate Gaussian distribution.
*   **Parameters:**
    *   $w_i = P(C = i)$: The weight of each component (prior probability).
    *   $\mu_i$: The mean of each component.
    *   $\Sigma_i$: The covariance of each component.
*   **The Problem:** If we knew which component generated each data point, we could easily calculate the parameters. However, this information (the component assignment) is usually hidden.

#### The Expectation-Maximization (EM) Algorithm
An iterative method to find Maximum Likelihood (or MAP) estimates of parameters in statistical models with unobserved (hidden) variables.
*   **Initialization:** Start with arbitrarily initialized parameters.
*   **E-Step (Expectation):** Calculate the probability that each data point was generated by each component, using the current parameter estimates. (This is like assigning points to clusters softly).
    *   $p_{ij}$: Probability that datum $x_j$ belongs to component $i$.
    *   $n_i = \sum_j p_{ij}$: Effective number of data points assigned to component $i$.
*   **M-Step (Maximization):** Recompute the parameters (mean, covariance, component weights) using the "soft assignments" from the E-Step to maximize the likelihood.
    *   Weights: $w_i \leftarrow n_i / N$
    *   Mean: $\mu_i \leftarrow \sum_j p_{ij} x_j / n_i$
*   **Iteration:** Repeat E-Step and M-Step until convergence. The log-likelihood is guaranteed to increase or stay the same with each iteration.
*   **Problem:** EM can get stuck in saddle points or local minima.
*   **Solution:** Random restart (run the algorithm multiple times with different initializations).

### Study Guide 2: Semi-Supervised Learning & Mixture Models
This guide focuses on Semi-Supervised Learning concepts, specifically exploring how unlabelled data can be utilized alongside labelled data, and how Mixture Models and Co-training are applied in this context.

#### Supervised vs. Semi-Supervised Learning
*   **Supervised Learning (SL):** Learns a prediction rule solely from labeled training data $\{(X_i, Y_i)\}$.
*   **Semi-Supervised Learning (SSL):** Learns a prediction rule using both a small amount of labeled data $\{(X_i, Y_i)\}_{i=1}^n$ and a large amount of unlabeled data $\{X_i\}_{i=1}^m$, where $m \gg n$.
*   **Goal of SSL:** To learn a better prediction rule than one based on labeled data alone. Unlabeled data can help reveal the underlying distribution or structure of the data.

#### Pseudo-Labeling (A simple SSL approach)
*   Train a learning model on the available labeled data.
*   Use this model to infer labels for the unlabeled pool, generating a "confidence score" (probability) for each prediction.
*   Select the predictions with confidence scores above a certain threshold (or the top-k most confident predictions) and add them to the labeled dataset.
*   **Important Condition:** The distribution of labeled and unlabeled data must be the same. A validation set is needed to ensure the model doesn't drift in the wrong direction.

#### Mixture Models in Semi-Supervised Learning
*   **Generative Approach:** Assumes knowledge of the model form $P(X, Y | \theta)$.
*   **Likelihoods:**
    *   **Labeled Data:** We maximize $P(X_l, Y_l | \theta)$.
    *   **Labeled + Unlabeled Data:** We maximize the joint and marginal likelihood: $\sum_{Y_u} P(X_l, Y_l, X_u, Y_u | \theta)$.
*   **Gaussian Mixture Models (GMM):** Often used for continuous data (e.g., image classification).
*   **Learning via EM:** The Expectation-Maximization algorithm is used to find the parameters $\theta$. Unlabeled data influences the model by shifting the decision boundary to better fit the overall data distribution.

#### EM for Gaussian Mixture Models (with Labeled and Unlabeled Data)
1.  **Initialization:** Start by calculating Maximum Likelihood Estimates (MLE) for parameters $\theta = \{w, \mu, \Sigma\}$ using only the labeled data $(X_l, Y_l)$.
2.  **E-step:** For all unlabeled data $x \in X_u$, compute the expected label $P(y|x, \theta)$. This is the probability that an unlabeled point belongs to class $y$.
3.  **M-step:** Update the MLE parameters $\theta$ using both the originally labeled data and the newly "soft-labeled" data $X_u$.
4.  **Iterate:** Repeat steps 2 and 3 until convergence.

#### Assumptions and Dangers of GMMs
*   **Core Assumption:** The method assumes the data actually comes from the specified mixture model (e.g., normal distributions).
*   **The Danger:** If the assumption is wrong (e.g., the true distribution is not Gaussian), adding unlabeled data can degrade performance. The model might confidently cluster the data based on the wrong structure.
*   **Heuristics to Lessen Danger:**
    *   Carefully construct the generative model (e.g., use multiple Gaussians per class if the class distribution is complex).
    *   Down-weight the influence of unlabeled data in the likelihood function using a parameter $\lambda < 1$.

#### Co-training
*   **Concept:** Applied when instances can be represented by two distinct "views" or feature sets (e.g., a web page can be described by its text content AND the text of hyperlinks pointing to it).
*   **Assumptions:**
    *   The feature split $x =[x^{(1)}; x^{(2)}]$ exists.
    *   Each view ($x^{(1)}$ or $x^{(2)}$) alone is sufficient to train a good classifier.
    *   The views $x^{(1)}$ and $x^{(2)}$ are conditionally independent given the class.
*   **Algorithm (Blum & Mitchell '98):**
    1.  Train a classifier on view 1 ($f^{(1)}$) and a classifier on view 2 ($f^{(2)}$) using the labeled data.
    2.  Use $f^{(1)}$ and $f^{(2)}$ to classify the unlabeled data separately.
    3.  Add the most confident predictions from $f^{(1)}$ to the labeled set for $f^{(2)}$, and vice versa.
    4.  Repeat.

### Study Guide 3: Unsupervised Learning - Clustering and Dimensionality Reduction
This guide details unsupervised learning, focusing heavily on K-means clustering and Principal Component Analysis (PCA).

#### What is Unsupervised Learning?
*   **Definition:** Statistical tools for data that has features ($X$) but no labels ($y$).
*   **Goal:** Discover interesting patterns or properties within the data (e.g., identifying subgroups, visualizing high-dimensional data).
*   **Challenges:**
    *   Goals are often not clearly defined (exploratory).
    *   Difficult to assess performance because there is no "right answer."
*   **Two Main Types:**
    *   **Cluster Analysis:** Finding homogenous subgroups.
    *   **Dimensionality Reduction:** Finding a low-dimensional representation to characterize data.

#### Clustering Concepts
*   **Goal:** Find subgroups where observations within a group are similar, but differ across groups.
*   **Types of Clustering:**
    *   Centroid-based (e.g., K-means)
    *   Hierarchical
    *   Model-based (representing clusters by parametric distributions)
*   **Hard vs. Soft Clustering:**
    *   Hard: Each observation belongs to exactly one cluster.
    *   Soft: Observations have probabilities of belonging to multiple clusters.

#### K-means Clustering
*   **Properties:**
    1.  Each observation belongs to at least one of $K$ clusters.
    2.  Clusters are non-overlapping.
*   **Objective:** Minimize the within-cluster variation (usually measured by squared Euclidean distance).
*   **Algorithm:**
    1.  Initialize by randomly assigning each observation to one of $K$ clusters.
    2.  **Iterate until assignments stop changing:**
        *   Compute the centroid (mean vector) for each cluster.
        *   Re-assign each observation to the cluster with the closest centroid.
*   **Properties of the Algorithm:**
    *   The objective function (within-cluster variation) will never increase during iteration.
    *   It finds a local minimum, meaning different initializations can lead to different final clusters.
*   **Pros:** Easy to implement and understand.
*   **Cons:**
    *   Sensitive to initializations and outliers (perturbations).
    *   Assumes clusters are spherical and features are equally scaled.
    *   Requires specifying $K$ (number of clusters) beforehand.

#### Dimensionality Reduction and PCA
*   **Curse of Dimensionality:** As dimensions increase, model performance can degrade. High dimensions require exponentially more data and can lead to overfitting.
*   **Goal:** Project high-dimensional data into a lower-dimensional space while retaining as much critical information (variance) as possible.
*   **Principal Component Analysis (PCA):**
    *   **Objective:** Find the directions (Principal Components) along which the data varies the most. Spreading the data out maximizes the information retained.
    *   **Variance:** Measures how spread out data is along a single axis.
    *   **Covariance:** Measures how two variables vary together. A positive covariance means they increase together; negative means one increases while the other decreases.
    *   **Covariance Matrix ($\Sigma$):** A matrix representing the variance of each feature on the diagonal and the covariance between features on the off-diagonals.
    *   **Linear Transformations:** Matrix multiplication translates and reshapes data. Multiplying a dataset by a transformation matrix changes its shape (e.g., a circle becomes an ellipse).
    *   **Eigenvectors and Eigenvalues:**
        *   **Eigenvectors ($v$):** Directions in space that remain unchanged (only scaled) after a linear transformation. These become the Principal Components.
        *   **Eigenvalues ($\lambda$):** The magnitude by which the eigenvector is scaled. A larger eigenvalue indicates more variance along that eigenvector's direction.
    *   **PCA Process:**
        1.  Center the data (subtract the mean).
        2.  Calculate the Covariance Matrix ($\Sigma$).
        3.  Find the Eigenvectors and Eigenvalues of $\Sigma$.
        4.  Sort Eigenvectors by their corresponding Eigenvalues (highest to lowest). The eigenvector with the highest eigenvalue is the First Principal Component (PC1).
        5.  Project the data onto the chosen top Eigenvectors to achieve dimensionality reduction (e.g., project from 5D to 2D by using only the top 2 eigenvectors).
