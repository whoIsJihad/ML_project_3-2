# Pulse Code Modulation (PCM) System Overview

**Pulse Code Modulation (PCM)** is the most fundamental and widely used method for converting an analog signal into a digital signal. The entire process consists of three main stages: [[1.1 Sampling|Sampling]], [[1.2 Quantization|Quantization]], and [[1.3 Encoding|Encoding]].

## PCM Transmitter Block Diagram

A typical PCM transmitter consists of the following components in sequence:

1.  **Low-Pass Filter (LPF):** The analog input signal $m(t)$ is first passed through a low-pass filter. This filter is an **anti-aliasing filter** that bandlimits the signal to a maximum frequency, $f_{max}$, to satisfy the conditions of the [[Nyquist-Shannon Sampling Theorem]].

2.  **Sampler:** The bandlimited signal is then fed to a sampler, which takes samples of the signal at a rate of $f_s \ge 2f_{max}$. The output is a discrete-time, continuous-amplitude signal.

3.  **Quantizer:** The sampled amplitudes are processed by a quantizer, which maps each continuous amplitude value to one of a finite number of discrete levels, $L$.

4.  **Encoder:** The encoder converts each discrete amplitude level into an $n$-bit binary code word, where $n = \log_2(L)$. The output of the encoder is a serial bitstream that represents the original analog signal.

## PCM Receiver Block Diagram

The PCM receiver performs the reverse operation to reconstruct the original analog signal from the incoming digital bitstream.

1.  **Regenerative Repeater:** (Often used in long-distance transmission) The digital signal can become distorted by noise and attenuation. A regenerative repeater reshapes and retimes the pulses to restore the signal to its original clean digital form.

2.  **Decoder:** The decoder groups the incoming bits into $n$-bit code words and converts each code word back to its corresponding quantized amplitude level.

3.  **Reconstruction Filter (Sample-and-Hold):** The sequence of discrete amplitude levels is used to generate a staircase-like approximation of the original sampled signal.

4.  **Low-Pass Filter (LPF):** The final stage is another low-pass filter, often called a **smoothing filter**. This filter removes the high-frequency components introduced by the staircase approximation and smooths the signal to recover the original analog waveform. The ideal reconstruction filter is a low-pass filter with a cutoff frequency of $f_{max}$.

The reconstructed signal, $\hat{m}(t)$, is an approximation of the original signal $m(t)$. The accuracy of the reconstruction depends on the sampling rate and, more significantly, on the fidelity of the quantization process, which is determined by the number of quantization levels $L$.
