# Quantization Noise

**Quantization noise** (or quantization error) is the error introduced during the [[1.2 Quantization|quantization]] process. It is the difference between the original analog sample value and the chosen discrete quantization level. This error is a fundamental limitation of converting an analog signal to a digital one.

## Definition

Let $m$ be the value of an original analog sample and $m_q$ be its quantized value. The quantization error, $e_q$, is:

$e_q = m - m_q$

In a [[2.2 Uniform Quantization|uniform quantizer]] with a step size of $\Delta V$, the error for any given sample is bounded. Since the quantized level is chosen to be the closest one to the original sample, the magnitude of the error will not exceed half of the step size.

$-\frac{\Delta V}{2} \le e_q \le \frac{\Delta V}{2}$

## Quantization Noise Power

To analyze the impact of this error, we model it as a noise signal. The **quantization noise power**, $N_q$, is the variance of the quantization error, $\sigma_{e_q}^2$.

To derive the noise power, we make two key assumptions about the statistical properties of the quantization error:

1.  **Uniform Distribution:** The error $e_q$ is a random variable that is uniformly distributed over the interval $[-\frac{\Delta V}{2}, \frac{\Delta V}{2}]$. This is a reasonable assumption when the number of quantization levels $L$ is large and the signal traverses many levels.
2.  **Uncorrelated:** The error is uncorrelated with the input signal and is white (i.e., its power spectral density is flat).

The probability density function (PDF) of a uniform distribution over the interval $[a, b]$ is $1/(b-a)$. For our error, $a = -\Delta V/2$ and $b = \Delta V/2$, so the PDF, $p(e_q)$, is:

$p(e_q) = \frac{1}{\Delta V}$ for $-\frac{\Delta V}{2} \le e_q \le \frac{\Delta V}{2}$, and 0 otherwise.

The noise power (variance) is the expected value of the squared error, $E[e_q^2]$. For a zero-mean uniform distribution, this is:

$N_q = \sigma_{e_q}^2 = E[e_q^2] = \int_{-\infty}^{\infty} e_q^2 p(e_q) de_q = \int_{-\Delta V/2}^{\Delta V/2} e_q^2 \frac{1}{\Delta V} de_q$

$N_q = \frac{1}{\Delta V} \left[ \frac{e_q^3}{3} \right]_{-\Delta V/2}^{\Delta V/2} = \frac{1}{3\Delta V} \left[ \left(\frac{\Delta V}{2}\right)^3 - \left(-\frac{\Delta V}{2}\right)^3 \right]$

$N_q = \frac{1}{3\Delta V} \left[ \frac{(\Delta V)^3}{8} + \frac{(\Delta V)^3}{8} \right] = \frac{1}{3\Delta V} \left[ \frac{2(\Delta V)^3}{8} \right] = \frac{(\Delta V)^2}{12}$

### In terms of L and $m_p$

Since the step size $\Delta V = \frac{2m_p}{L}$, we can express the noise power in terms of the number of levels $L$ and the peak signal amplitude $m_p$:

$N_q = \frac{(2m_p/L)^2}{12} = \frac{4m_p^2}{12L^2} = \frac{m_p^2}{3L^2}$

This is a fundamental result. It shows that the quantization noise power is inversely proportional to the square of the number of quantization levels ($L^2$). Therefore, doubling the number of levels reduces the noise power by a factor of four.
