# Encoding

**Encoding** is the final stage in the [[1. Analog-to-Digital Conversion|analog-to-digital conversion]] process, following [[1.1 Sampling|sampling]] and [[1.2 Quantization|quantization]]. It involves assigning a unique binary code word to each of the discrete amplitude levels produced by the quantizer.

## Principle

After quantization, the signal is represented by a sequence of discrete amplitude levels. If there are $L$ quantization levels, then a binary code is needed to uniquely identify each level.

The number of bits, $n$, required to represent $L$ levels is given by:

$n = \log_2(L)$

If $L$ is a power of 2, for instance $L = 2^n$, then $n$ will be an integer. If $L$ is not a power of 2, the number of bits must be rounded up to the next integer value, $n = \lceil \log_2(L) \rceil$.

For example, if a quantizer has $L=256$ levels, the number of bits required per sample is:

$n = \log_2(256) = 8$ bits

## Process

The encoder maps each quantized amplitude level to its corresponding $n$-bit binary code word. The output of the encoder is a serial bitstream, which is a sequence of 0s and 1s. This bitstream is the final digital representation of the original analog signal.

## Data Rate

The **data rate** (or bit rate), $R$, of the resulting digital signal is the total number of bits transmitted per second. It is calculated as the product of the sampling rate, $f_s$, and the number of bits per sample, $n$.

$R = f_s \times n$

For example, for a signal sampled at 8 kHz with 8 bits per sample, the data rate is:

$R = 8000 \text{ samples/second} \times 8 \text{ bits/sample} = 64,000 \text{ bits/second (bps)}$ or 64 kbps.

This data rate is a critical parameter in digital communications as it determines the required [[Bandwidth]] of the transmission channel.

## Example

-   **Analog Signal:** $m(t)$
-   **Sampling:** The signal is sampled at $t = nT_s$, resulting in $m[n]$. Let's say one sample has an amplitude of 3.5V.
-   **Quantization:** The quantizer maps the 3.5V sample to the nearest level. Assume the levels are integers and the nearest level is 3. The quantized value is $m_q[n] = 3$.
-   **Encoding:** The encoder looks up the binary code for level 3. If we are using 4-bit codes ($L=16$ levels), the code for level 3 might be `0011`. This binary sequence is then transmitted.
