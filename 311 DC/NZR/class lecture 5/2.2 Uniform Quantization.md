# Uniform Quantization

**Uniform quantization** is a type of [[1.2 Quantization|quantization]] where the entire dynamic range of a signal is divided into a number of quantization levels of equal size. It is the most straightforward method of amplitude discretization.

## Principle

Assume an analog signal's amplitude is confined to the range $[-m_p, +m_p]$, where $m_p$ is the peak amplitude. In uniform quantization, this total range of $2m_p$ is divided into $L$ equal sub-intervals.

## Quantization Step Size

The size of each of these intervals is called the **quantization step size** or **quantum**, denoted by $\Delta V$. It is defined as:

$\Delta V = \frac{2m_p}{L}$

Where:
-   $m_p$ is the peak voltage of the signal.
-   $L$ is the number of quantization levels.

Each sample of the analog signal is assigned to the quantization level closest to its actual value. For instance, a common method is to assign the midpoint of the interval as the representative quantization value.

## Example

Consider a signal with a peak amplitude $m_p = 4V$. The full dynamic range is from -4V to +4V, a total of 8V. We decide to use $L=8$ quantization levels.

The step size is:
$\Delta V = \frac{2 \times 4V}{8} = 1V$

The quantization intervals and their corresponding representative levels (midpoints) would be:

| Interval           | Midpoint (Quantized Value) |
| ------------------ | -------------------------- |
| (+3.5V, +4.5V]     | +4V                        |
| (+2.5V, +3.5V]     | +3V                        |
| (+1.5V, +2.5V]     | +2V                        |
| (+0.5V, +1.5V]     | +1V                        |
| (-0.5V, +0.5V]     | 0V                         |
| (-1.5V, -0.5V]     | -1V                        |
| (-2.5V, -1.5V]     | -2V                        |
| (-3.5V, -2.5V]     | -3V                        |
| (-4.5V, -3.5V]     | -4V                        |
*(Note: Boundaries must be handled consistently, e.g., using half-open intervals.)*

If a sampled value is, for example, +2.8V, it falls into the interval (+2.5V, +3.5V], and it would be quantized to the value +3V. The quantization error in this case would be $2.8V - 3V = -0.2V$.

## Limitations

The main drawback of uniform quantization is that the [[2.3 Quantization Noise|quantization noise]] power is the same for all signal levels. For signals where small amplitudes are much more frequent than large amplitudes (like human speech), this method is inefficient. It results in a poor [[2.4 Signal-to-Noise Ratio in PCM|signal-to-noise ratio]] for low-level (quiet) signals. This limitation is addressed by [[2.5 Non-Uniform Quantization (Hard)|non-uniform quantization]].
