# Quantization

**Quantization** is the process of mapping a large set of input values (such as the amplitudes of a sampled signal) to a smaller, finite set of output values. It follows the [[1.1 Sampling|sampling]] stage in [[1. Analog-to-Digital Conversion|analog-to-digital conversion]].

## Principle

After sampling, the signal $m[n]$ is discrete in time, but its amplitude values are still continuous. Quantization discretizes these amplitude values. The range of possible amplitudes is divided into a finite number of levels, and each sample's amplitude is approximated by the nearest quantization level.

## Process

1.  **Define Amplitude Range:** The full dynamic range of the signal, from its minimum to maximum possible values, is determined. Let this range be from $-m_p$ to $+m_p$.
2.  **Divide into Levels:** This range is divided into $L$ discrete and contiguous intervals.
3.  **Assign Quantization Value:** Each interval is represented by a single discrete value. Any sample whose amplitude falls within a particular interval is assigned the representative value of that interval.

The output of the quantizer is a sequence of numbers, $m_q[n]$, where each value is one of the pre-defined $L$ levels.

## Types of Quantization

1.  **[[2.2 Uniform Quantization|Uniform Quantization]]**: The intervals are of equal size. This is the simplest method but may not be optimal for all signal types.
2.  **[[2.5 Non-Uniform Quantization (Hard)|Non-Uniform Quantization]]**: The intervals are of different sizes. Smaller intervals are used for amplitude ranges where the signal is more likely to occur, and larger intervals are used for ranges where the signal is less likely. This can improve the overall signal-to-noise ratio.

## Quantization Error

The difference between the original sampled value $m[n]$ and the quantized value $m_q[n]$ is the **quantization error** or **[[2.3 Quantization Noise|quantization noise]]**.

$e[n] = m[n] - m_q[n]$

This error is an unavoidable consequence of the quantization process and is a primary source of imperfection in digital communication systems.

## Next Steps

Once the signal has been quantized, the final step in the conversion process is [[1.3 Encoding|Encoding]], where the discrete amplitude levels are represented by binary code words.
