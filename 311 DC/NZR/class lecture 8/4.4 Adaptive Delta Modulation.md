# Adaptive Delta Modulation (ADM)

**Adaptive Delta Modulation (ADM)** is an advanced form of [[4.1 Delta Modulation System Overview|Delta Modulation (DM)]] designed to overcome the limitations of a fixed step size. In ADM, the step size, $\Delta$, is not constant but is varied "adaptively" based on the characteristics of the input signal.

## Motivation

A standard DM system with a fixed step size suffers from a trade-off between two types of error:
1.  **[[4.2 Slope Overload Distortion|Slope Overload Distortion]]**: Occurs when the signal slope is steep and the step size is too small.
2.  **[[4.3 Granular Noise|Granular Noise]]**: Occurs when the signal slope is small and the step size is too large.

An optimal, fixed step size is always a compromise. The ideal scenario would be to use a large step size when the signal is changing rapidly and a small step size when the signal is relatively flat. This is precisely what ADM accomplishes.

## Principle

The core idea of ADM is to adjust the step size based on the recent output of the quantizer. A logic circuit monitors the stream of transmitted bits (the `+1`s and `-1`s) and uses that information to infer the behavior of the input signal.

A common adaptation strategy is as follows:

-   **If consecutive output bits are the same** (e.g., `+1, +1, +1` or `-1, -1, -1`), it implies that the staircase approximation is consistently falling behind or leading the signal. This is an indication of a steep slope and that the system is approaching or is already in a state of slope overload.
    -   **Action:** Increase the step size, $\Delta$. This allows the staircase to change more rapidly to catch up with the signal.

-   **If consecutive output bits are different** (e.g., `+1, -1, +1, -1`), it implies that the staircase is oscillating around the signal. This is an indication of a small signal slope and the presence of granular noise.
    -   **Action:** Decrease the step size, $\Delta$. This reduces the magnitude of the oscillations, thus reducing the granular noise.

## Implementation

The ADM transmitter is similar to a standard DM transmitter but includes an additional **step-size adaptation logic** block.

1.  The input signal is compared to the reconstructed signal.
2.  The difference is fed to a 1-bit quantizer, which outputs a bitstream, $b[k]$.
3.  This bitstream is both transmitted and fed into the step-size adaptation logic.
4.  The logic examines the pattern of $b[k]$ (e.g., the current and previous bits) and computes the next step size, $\Delta[k]$.
5.  The accumulator then creates the next reconstructed sample using this new step size: $\hat{m}[k] = \hat{m}[k-1] + \Delta[k] \cdot b[k]$.

The receiver must use the exact same adaptation logic. Since the logic at the transmitter only depends on the transmitted bitstream, the receiver can perfectly replicate the sequence of step sizes, $\Delta[k]$, by looking at the incoming bitstream, $b[k]$. This allows the receiver's accumulator to reconstruct the same adaptive staircase signal without needing any separate, explicit information about the step size.

## Advantages

-   **Improved Dynamic Range:** ADM can handle a much wider range of input signal amplitudes and slopes compared to standard DM.
-   **Reduced Overall Noise:** It significantly reduces both slope overload distortion and granular noise, resulting in a better overall Signal-to-Noise Ratio (SNR).
-   **Bandwidth Efficiency:** It achieves this improved performance without increasing the bit rate (which remains at $1 \times f_s$).

Because of these advantages, adaptive delta modulation is a much more practical and widely used technique than its simpler, fixed-step-size counterpart. A common standardized implementation is **Continuously Variable Slope Delta (CVSD)** modulation, which is used in many digital voice communication applications, including Bluetooth headsets.
