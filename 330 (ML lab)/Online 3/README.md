## 📊 Key Concepts You Must Know

### Ensemble Methods
- ✅ **Bagging**: Reduces variance, uses bootstrapping
- ✅ **Random Forest**: Bagging + random feature selection
- ✅ **AdaBoost**: Sequential, focuses on hard examples
- ✅ **Gradient Boosting**: Sequential, fits to residuals
- ✅ **XGBoost**: Regularized gradient boosting

### XGBoost Hyperparameters (Top 5)
1. `n_estimators`: Number of trees (50-500)
2. `max_depth`: Tree depth (3-10)
3. `learning_rate`: Step size (0.01-0.3)
4. `subsample`: Data sampling ratio (0.7-1.0)
5. `reg_lambda`: L2 regularization (0-10)

### Base Learners
- **Decision Stump** (depth=1): Best for AdaBoost
- **Shallow Tree** (depth=3-5): Good for boosting
- **Deep Tree** (depth=10+): Good for bagging
- **Linear Models**: Don't benefit much from ensembling

### Evaluation
- **Accuracy**: Main metric for balanced data
- **F1-Score**: Better for imbalanced data
- **Cross-Validation**: Use cv=5 for reliability
- **Overfitting Check**: Compare train vs test accuracy
